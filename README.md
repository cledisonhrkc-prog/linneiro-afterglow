# LINNEIRO — AFTERGLOW

AI pop singer built from a real photograph. Debut album of **20 original English pop songs**.

This is the official player, lyrics, stills, and music-video clips.

## For ChatGPT / other AIs

You can read this whole repo. Start here:

| What | Where |
|---|---|
| Artist + 20 songs + full lyrics | `src/lib/catalog.ts` |
| Lyrics only | `public/export/linneiro-lyrics.txt` |
| Stills (one image per track) | `public/stills/01.jpg` … `20.jpg` |
| Covers | `public/covers/` |
| Artist face / hero | `public/artist/` |
| Clips 01–10 (small MP4) | `public/pack1/` |
| Clips 11–20 (small MP4) | `public/pack2/` |
| Full clips | `public/videos/` |

Do **not** ask the owner for GitHub passwords. This repo is enough.
